Pokemon Battler Simulator

Este proyecto es una **simulación de combate de Pokémon** que he desarrollado como parte de un ejercicio personal para aprender y practicar programación. El objetivo de este proyecto es mejorar mis habilidades en el desarrollo de sistemas de combate, backend y frontend, así como en la integración de APIs y gestión de bases de datos.
### **¿Por qué este proyecto?**
Este es un **proyecto de aprendizaje** en el que exploro diversos aspectos de la programación, como:
- **Lógica de juegos**, implementando el sistema de combate de Pokémon.
- **Desarrollo full-stack**, utilizando ASP.NET para el backend y Vue.js para el frontend.
- **Simulaciones y pruebas**, creando un entorno para realizar pruebas del sistema de combate.

Este proyecto es **un ejercicio personal**, por lo que la implementación y el diseño pueden no ser ideales o estar completos. Está en constante evolución, y mi objetivo es seguir mejorando y optimizando el código.


## Tecnologías:
* Backend: .Net 8 (ASP .Net Core)
* Frontend: Vue 3
* Base de datos: Json Repository
* API: RESTful que maneja Pokémon, movimientos, habilidades y batallas
* Pruebas: XUnit, pruebas unitarias y de integración

## Roadmap:
* **Backend**
 - Completar todos los efectos de movimiento y eventos de batalla
 - Completar los elementos CRUD con sus validaciones.

* **Frontend**
  - Mejorar la interfaz de usuario para hacerla más dinámica e interactiva
 
* **Multijugador**
  - Integrar un sistema de combate multijugador

* **GenAI**
  - Explorar uso de inteligencia artificial generativa para dialogos entre npcs o analisis de partidas.
